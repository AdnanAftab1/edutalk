# Parent Teacher Communication App

Build as a college semester project in Software Engineering

## 🚀 Getting Started

Follow these steps to get the development server up and running on your local machine.

### Prerequisites

Create a `.env` file in the root directory and add the following environment variables:

```env
# Connection string for your MySQL database
DATABASE_URL="mysql://USER:PASSWORD@HOST:PORT/DATABASE"

# App password for email services
MY_PASSWORD="your-email-app-password"
```


```bash
npm install
npm run dev
``` 


Open http://localhost:3000 with your browser to see the result.
